01
首页学习入口

用一个目标输入区承接两种意图：学习与解决问题

DLI 提供开发者训练的直接对标；Hyperknow 提供同一输入区切换“课程生成 / 即时协助”的交互启发。

当前问题：怎样让用户先表达“我想学什么”或“我正在解决什么”，同时仍能继续已有课程和进入个人知识地图？

NVIDIA Deep Learning Institute

打开官网 ↗
直接竞品 · 开发者训练与认证

DLI 将自学课程、讲师工作坊、学习路径和认证放在统一训练入口，并强调专家课程、真实案例、云端 GPU 实验环境和可获得的证书。

可借鉴

  • 首屏先说清训练面向的开发者能力，而不是罗列资源数量。
  • 把自学、实操环境、专家指导和能力证明连接成完整闭环。
  • 课程入口同时展示领域、学习方式和最终可获得的实践结果。

不照搬：DLI 的入口更像训练目录；我们的首要任务是先理解用户目标，再从课程与问题解决链路中选择合适响应。

Hyperknow

打开产品 ↗
交互参考 · 双意图目标输入

首页在同一输入框上方区分“打造课程”和“即时协助”，用户不必先理解产品结构，只需先选择想系统学习还是立刻获得帮助。

转译到当前方案

  • 将模式转译为“学习 / 解决问题”，两个标签共用同一目标输入框。
  • 学习模式组织课程与长期计划；解决问题模式接收任务、报错、环境和期望结果。
  • 输入区下方保留继续学习，知识地图入口放在继续学习标题后作为全局视角切换。

不照搬：不使用“自学 / 即时协助”这类实现视角文案；用户关心的是目标类型，不是系统将采用哪一种生成方式。

Microsoft Learn

打开官网 ↗
直接参考 · 开发者学习平台

首页用具体训练内容和职业目标两条入口解释学习意图，课程卡直接显示类型、时长、角色和难度。

可借鉴

  • 把任务入口写成用户目标，而不是产品栏目。
  • 继续学习卡保留进度和最近位置；知识地图按钮作为视角切换。
  • 用课程模块、学习路线、计划等明确类型，降低概念混淆。

不照搬：内容类型过多时容易把首页变成资源目录，我们仍以当前任务为主。

roadmap.sh

打开官网 ↗
补充参考 · 路线与知识导航

用一句目标描述和角色路线列表帮助用户快速选择，同时把路线、项目创意与学习内容分成不同入口。

可借鉴

  • 知识地图入口应承诺“看清位置和下一步”，而非泛泛的“查看更多”。
  • 首页只展示当前推荐方向，复杂网络放到全屏地图。
  • 允许目标驱动检索并重组已有课程。

不照搬：线性路线不能代表昇腾密集且互相依赖的知识网络。

02
课程预览

左侧定位课程资源，右侧展开选中单元的完整内容

Hyperknow 把课程入口、单元导航和单元内部讲次放在同一预览页，用户能先看全局，再判断从哪里开始。

当前问题：如何让用户看懂课程由哪些单元组成，并区分单元、资料、练习三类学习资源及其完成状态？

Hyperknow · 课程预览

打开产品 ↗
直接参考 · 课程资源与单元详情

左侧先在“单元 / 资料 / 练习”三类资源间切换；单元列表承担全局导航。选中单元后，右侧沿时间线展开讲次、项目与综合评估，并保留下一步动作。

可借鉴

  • 左侧负责资源类型和单元定位，右侧只讲清当前单元内部结构。
  • 讲次、项目、测验使用不同图标和状态，避免把所有内容都叫“课节”。
  • 已掌握、熟练、熟悉、已尝试、未开始等状态形成课程级进度语言。
  • 下一步入口跟随当前进度，而不是固定跳回第一项。

不照搬：上传材料属于课程编辑能力，不应默认占据普通学习者的预览主链路；课程封面也不应挤压结构空间。

NVIDIA DLI · 结果与实践承诺

查看培训体系 ↗
补充参考 · 实践环境与能力证明

DLI 将实操实验、云端 GPU 环境、真实案例和部分课程证书作为学习价值的一部分，课程预览不只介绍知识目录。

转译到当前方案

  • 课程首屏说明适用基础、预计时长、实践数量和环境要求。
  • 选中单元时同时显示会完成的任务、会留下的证据和将点亮的能力。
  • 真实环境复现信息与课程结构并列，但保持为辅助判断区。

不照搬：认证与课程完成不能混为一谈；证书、能力点亮和真实任务证据需要分别表达。

DeepLearning.AI

查看课程 ↗
直接参考 · AI 课程平台

课程目录把类型、难度、讲师、合作方和学习结果放在同一个判断面，先帮助用户筛选，再进入详情。

可借鉴

  • 课程首屏明确适用基础、预计时长、实践数量和最终产出。
  • 课程模块用用户能理解的阶段性结果命名。
  • 课程来源和环境验证信息与课程结构分区呈现。

不照搬：营销式大图会挤压复杂课程结构，当前预览页继续去除装饰性 Banner。

Microsoft Learn · 内容层级

查看内容类型 ↗
结构参考 · 计划 / 路线 / 模块 / 单元

官方明确区分 Plan、Learning Path、Module 和 Unit，每一级对应不同的结果与内容粒度。

可借鉴

  • 左侧固定课程模块，右侧选中模块后展开单元和课节。
  • 课节类型只保留课程、实践、测验三个可行动标签。
  • 课程要点属于课节内部，进入画布后再呈现。

不照搬：“学习阶段”容易被理解为覆盖整条学习路径，当前统一使用“课程模块”。

03
白板学习

板书是主内容，AI 交流围绕当前板书持续发生

Hyperknow 将手写板书、示意图、课程要点、文字/语音交流和对话历史放在同一学习上下文中。

当前问题：怎样让用户决定板书的进行与停止状态，并能对任何不理解的内容随时提问，同时不遮挡老师原始板书？

Hyperknow · 交流方式选择

打开产品 ↗
交互参考 · 仅文字 / 语音 + 文字

正式开始前先选择与“老师”的交流方式。语音模式下，用户开口后讲解会暂停，先回答问题，再从暂停位置继续。

可借鉴

  • 将语音/文字作为交流偏好，而不是两套学习页面。
  • 语音提问触发“暂停—回答—恢复”，使板书状态始终可感知。
  • 学习中允许随时切换输入方式，避免开始前的选择成为限制。

不照搬：不把交流方式做成阻断式必选步骤；可给出推荐默认值，并允许直接进入后再调整。

Hyperknow · 板书与对话历史

打开产品 ↗
结构参考 · 画布主视角 + 右侧上下文

板书自然铺在大画布上，混合手写文字、表格、公式、图解与选择题；右侧保留与板书对应的对话历史，画布边缘弱化展示课程要点和当前进度。

转译到当前方案

  • 老师原始板书保持黑色/深灰自然排版，不额外框成卡片。
  • 课程要点收进课节标题后的大纲按钮；AI 学伴中只弱展示链路进度和当前要点。
  • 选中板书后出现“问一下、用图解释、换个说法”；临时解释层用浅蓝半透明描图纸视觉并连接原句。
  • 提问、语音、笔记和计划都属于右侧 AI 学伴的子功能；学伴可悬浮、收起，并在 IDE 出现时贴合 IDE 右侧。

不照搬：右侧对话历史不固定占用过宽空间；画布始终是学习主区域，学伴宽度和出现时机随任务切换。

Brilliant

查看课程 ↗
体验参考 · 互动理解

把解释、可视化模型、问题与即时反馈连续组织，让用户通过操作构建理解。

可借鉴

  • 一次只围绕一个知识对象提供反馈和下一步。
  • 可视化解释在原内容附近出现，保持来源关联。
  • 完成状态以理解和实践证据表达，不只记录播放进度。

不照搬：昇腾课程需要保留完整工程上下文，不能切成过多脱离环境的小游戏。

Khanmigo

查看产品 ↗
交互参考 · 上下文追问

学习助手强调引导思考，并将对话绑定到正在学习的内容，而不是提供无上下文的通用聊天。

可借鉴

  • 选中板书后出现“问一下、用图解释、换个说法”。
  • 临时解释层标注 AI 来源，用浅色描图纸视觉与原板书区分。
  • 恢复播放后自动收起；主动保存后进入学伴的笔记或计划。

不照搬：不让学伴长期占据画布主区域，右侧使用可收起浮窗。

04
在线 IDE

固定工作区承接“边学边实践”，比堆叠工具栏更重要

IDE 进入白板后成为稳定工作区，把当前课程任务、代码、运行检查和 AI 学伴连接成连续实践。

当前问题：如何让课程内容直接触发对应练习，并在代码、终端、运行结果与课程上下文之间保持连续？

HiDevLab 在线开发

打开官网 ↗
直接参考 · 昇腾在线开发环境

在进入环境前说明算力规格、镜像、资源调度、闲置关机与数据保留规则，降低使用风险。

可借鉴

  • 实践开始前确认算力、镜像、预计卡时和保存目录。
  • 课程为 IDE 预置工程与运行命令，减少环境准备。
  • 运行日志、关键指标和环境版本自动成为验证证据。

不照搬：无需保留完整 WebIDE 的资源管理侧栏，课程场景只显示任务所需面板。

GitHub Codespaces

打开官网 ↗
补充参考 · 可复现开发环境

以仓库配置创建一致环境，让用户在浏览器或本地编辑器中恢复同一工程上下文。

可借鉴

  • 环境配置和课程版本绑定，支持中断后恢复。
  • 主区域默认代码编辑，底部终端/日志，右侧 AI 学伴。
  • 允许拖拽重排，但保留“一键恢复课程布局”。

不照搬：通用 IDE 的扩展和账户功能会增加噪声，学习模式需做任务化裁剪。

JetBrains Academy · Hyperskill 实践链路

查看竞品画布 ↗
直接参考 · 边学边实践与自动验证

课程内的当前任务可以直接在 IDE 中打开。IDE 同时保留代码、阶段说明、目标、检查与提交状态；完成验证后把结果带回项目进度，让“理解—尝试—反馈—继续学习”成为一条不中断的链路。

转译到当前方案

  • 板书讲到可实践的课程要点时，出现“进入练习”，打开与当前知识点绑定的预置工程。
  • IDE 固定区继承当前课节、文件、依赖、运行命令和验证条件；AI 学伴主动贴合右侧并继续使用同一上下文。
  • 运行后给出“尝试中 / 需调整 / 已通过”，日志和关键指标自动成为学习证据。
  • 练习通过后点亮对应课程要点和能力状态，并提供“回到板书继续”而不是把用户留在工具里。

不照搬：不要求用户跳到外部桌面 IDE，也不暴露完整通用开发工具；课程画布内保留精简、可恢复的实践区。

05
AI 学伴

学伴贯穿预习、实时帮助与总结复盘

同一学伴在首页、课程预览、白板、IDE 和知识地图中共享个人状态与当前上下文，在学习前后也能继续组织知识。

当前问题：怎样让学伴在课前帮助建立预期、学习中理解当前内容、课后完成总结，同时统一能力缺口、笔记和计划？

Khanmigo

打开官网 ↗
直接参考 · AI 导师

核心价值是“引导用户自己得出答案”，并通过对话持续感知学习上下文。

可借鉴

  • 默认提供与当前板书/代码相关的建议问题。
  • 回答中明确引用课程要点、日志或知识节点。
  • 能力缺口与路线建议给出原因和证据。

不照搬：用户可以直接要求答案，但系统应同时展示推理依据与可验证步骤。

Brilliant Koji

查看功能说明 ↗
补充参考 · 嵌入式导师

导师能看见用户正在处理的问题，并通过逐步提示定位卡点，减少重复描述上下文。

可借鉴

  • 学伴标题区展示当前课节与进行中的课程要点。
  • 笔记和计划作为右上角子功能唤出。
  • 完整知识地图与长期资产通过链接进入独立页面。

不照搬：能力同心环属于全局诊断，不应长期占据白板中的对话区域。

LearnKata · 上下文学习助手

查看竞品画布 ↗
直接参考 · 实时帮助与学习加工

AI 学伴固定在课程和资料旁边，能够引用当前空间中的文件继续对话，并把实时解释延伸为总结、思维导图、测验、闪卡和笔记。它既解决当下疑问，也帮助用户把内容加工成后续可复习的学习资产。

转译到当前方案

  • 课前预习：进入课节前生成学习目标、必要前置知识、概念关系和预计实践任务，帮助用户建立认知框架。
  • 学习中实时帮助：学伴自动携带当前板书、课程要点、资料页码、代码与日志，提供解释、换种说法、可视化解析和针对性追问。
  • 课后总结：根据实际学习过程生成本节摘要、已掌握内容、仍有疑问、实践证据和建议下一步，并由用户确认后写入笔记或计划。
  • 测验、笔记、闪卡和计划作为学伴右上角子功能唤出，主面板默认仍服务当前问题。

不照搬：不把所有学习工具同时铺在面板中；根据学习前、学习中、学习后的时机推荐最相关动作，避免右侧功能过载。

06
知识版图

知识关系与个人进度叠在同一张图上

Hyperskill 将主题按领域和先修关系组织，同时显示课程需要覆盖什么、项目已经覆盖什么，以及用户已学与待学的数量。

当前问题：怎样让用户一眼看见自己处于哪个领域和阶段，哪些已经完成，哪些是当前任务，下一步还能探索什么？

JetBrains Academy · Hyperskill

打开知识地图 ↗
直接参考 · 领域、先修关系与学习状态

知识地图由数千主题按领域组织，并用先修关系连接。页面区分课程需要学习、已经学习和项目已覆盖的主题；展开分类后可以查看某个主题的前置与后续依赖。

可借鉴

  • 领域、知识节点、课程覆盖与个人状态使用不同图形编码，避免混成一层。
  • 用户选择课程或项目后，只高亮相关节点和先修关系。
  • 顶部持续显示“待学习 / 已学习 / 实践覆盖”概览，让当前位置可量化。
  • 当前节点同时展示必须先学和可以继续探索的相邻节点。

不照搬：不能只按单一性能分数排行，还要奖励可复用性、解释质量和持续维护。

归纳

当前方案应坚持的五个设计决定

这些决定来自跨竞品共同模式，并结合昇腾知识密集、实践依赖环境和社区贡献需要复现的特点。

01 · 双意图入口

首页区分“学习 / 解决问题”

两种意图共用一个目标输入区；继续学习和知识地图承接已有学习状态。

02 · 资源分层

课程预览先定位类型，再展开单元

左侧区分单元、资料、练习并完成导航；右侧呈现选中单元的讲次、项目与综合评估。

03 · 上下文连续

板书、语音、对话和 IDE 共享当前上下文

画布保持主视角，AI 解释、笔记和计划围绕当前板书与代码出现，不写回老师原始板书。

04 · 位置可感知

知识版图同时表达关系与个人进度

领域、先修关系、课程覆盖、已完成状态和本次推荐路线分层编码，让用户知道自己在哪里。

05 · 贡献可验证

积分来自可复现影响

经验回填经过审核、环境复现和引用后计分，榜单明确展示每一笔得分原因。
