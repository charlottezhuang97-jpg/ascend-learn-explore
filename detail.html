EI0006未检测到 NPU 设备
运行时无法识别昇腾 NPU，通常是驱动未安装或环境变量未生效。
修复：确认已安装 driver 与 firmware，并执行 source set_env.sh
EE1001torch_npu 导入失败
torch_npu 与 torch 版本不匹配，import 时报 undefined symbol。
修复：安装与当前 PyTorch 版本对应的 torch_npu。
EL0004算子编译失败
Ascend C 算子在 build 阶段找不到头文件或工具链。
修复：检查 CANN 版本与 SDK 路径，确保 include 目录已加入编译参数。
