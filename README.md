# Ascend Developer 学习方案探索版

这是一个面向昇腾开发者的学习平台交互原型。它把“我想学什么／我正在解决什么开发问题”作为入口，通过开发场景、AI 学习方案、课程预览和沉浸式学习，把用户从目标表达带到知识学习、代码实践和问题解决。

当前仓库以静态 HTML、CSS 和 JavaScript 还原主要页面与交互，重点验证以下产品链路：

```text
首页表达目标 → AI 生成学习方案 → 查看课程预览 → 选择白板或视频 → 学习、实践与 AI 学伴辅助
```

## 主要场景

### 1. 首页：从开发目标开始

入口：[打开首页](index.html)

首页用于帮助用户快速说清楚“今天想学什么”或“正在解决什么开发问题”。页面包含：

- 自然语言搜索和快捷学习方向；
- “不知道从哪开始”的学习方向测试；
- 按开发场景浏览学习内容，包括模型训练、推理与部署、算子开发、调试与性能优化、AI 应用与智能体；
- 课程卡片的用户角色、典型场景、知识递进路线和学习成本；
- 开发者成长与贡献榜的公共摘要，分为学习成长、实战突破、社区共建。

首页承担发现和激励作用。个人进度、薄弱知识点和下一步建议进入“我的学习”或 AI 学伴中查看。

### 2. 查找学习资源

入口：[查找学习资源](find.html)

用于按开发任务、内容主题和学习类型筛选资源，帮助用户在课程、路径、文档和认证之间比较学习起点。

### 3. 按开发场景选择学习路径

入口：[学习路径](paths.html)

以知识递进和开发任务组织学习内容，而不是把课程、实验、测验当成一级分类。示例路径包括 AscendC 算子开发、CATLASS 算子开发、Triton 算子开发和算子开发调试调优。

### 4. 浏览自主学习课程或讲师培训

入口：[自主学习课程](courses.html) · [讲师指导培训](training.html)

课程卡片用于展示课程所属开发类型、用户角色、典型场景、知识路线、单元与讲次、实践强度、环境和课程评价等信息。

### 5. 查看课程详情并进入学习

入口：[课程详情](detail.html)

课程详情页用于确认课程是否适合当前目标，包括课程介绍、目录、学习成本、实践内容、环境和进入学习的操作。点击进入后，会先选择视频学习或白板学习。

### 6. 沉浸式课程学习：白板视图

入口：[进入课程学习](learn.html)（默认打开白板视图）

白板视图用于讲解概念、建立知识结构和推进课堂节奏：

- 中央区域是讲课画布，展示板书、课堂要点和字幕；
- 左上角提供关闭课程和课节标题；
- 右上角提供白板／视频切换、缩放、翻页、下载、AI 学伴和设置；
- 右侧默认唤起 AI 学伴，包含对话和“我的笔记”；
- 长按画布文字可以加入我的笔记；
- 底部字幕随板书内容推进。

白板状态包括：当前课节、板书页码、缩放比例、课堂要点选中状态、字幕播放状态、AI 学伴展开／收起，以及笔记为空或已加入内容。

### 7. 沉浸式课程学习：视频视图

入口：[进入课程学习](learn.html)，在右上角切换“视频”

视频视图将页面划分为三个可调整大小的大卡片，卡片圆角 12px、间距 8px：

1. 左侧视频区：默认占据更大空间，包含视频画面、播放控制、进度条和时间点标记；
2. 中间代码区：展示与视频时间点联动的代码片段，支持定位、复制、AI 解读和一键置入 IDE；
3. 右侧 IDE 区：用于编辑、运行和查看结果，可以收起，也可以拖动分隔条调整宽度。

视频下方提供四个辅助内容页签：代码全览、常见错误码、随堂测试、相关文档。进度条中的标记用于区分重要知识点、代码示例和实践节点。

视频视图状态包括：未播放、播放中、缓冲、暂停、已完成、时间点选中、代码片段选中、AI 解读展开、代码已置入 IDE、IDE 运行中、运行成功、运行失败，以及 IDE 收起状态。

### 8. 开发者认证

入口：[开发者认证](certification.html)

用于查看认证方向、考试状态和与学习路径的关系，帮助用户判断课程学习是否能继续进入认证准备。

### 9. 算子开发场景低保真参考

入口：[算子开发场景卡低保真](prototypes/operator-development-card-lowfi.html)

该页面用于验证课程卡默认态与悬浮态的信息层级：默认先呈现开发类型、适合角色、典型场景和知识递进路线，悬浮后再呈现学习成本、实践强度、认证和环境等信息。

## 本地查看

这是静态原型，可以直接打开 `index.html`。如果需要更接近真实站点的访问方式，也可以使用任意静态文件服务器打开项目根目录，然后访问：

```text
/index.html
/detail.html
/learn.html
```

原型中的课程、用户、学习进度和代码运行结果均为演示数据，用于验证信息结构和交互方向，尚未接入真实课程服务、认证系统、资料检索或在线运行环境。
