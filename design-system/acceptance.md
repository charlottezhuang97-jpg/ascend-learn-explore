# 验收层

每次新增页面、组件或交互，都至少完成以下检查。验收结果应写进对应 PR 或修改记录；未通过的项目必须标注原因和后续处理。

## Token 与组件

- [ ] 页面颜色、字体、间距、圆角、阴影和层级来自三层 Token。
- [ ] 没有新增重复的按钮、输入框、标签、卡片或面板视觉语言。
- [ ] 复杂页面使用已有场景模式；需要新模式时先走预览门禁。
- [ ] 组件定义了 default、hover、focus、disabled；异步任务定义 loading、success、error。

## 布局与信息密度

- [ ] 容器、栅格和固定区域先于文本细节确定。
- [ ] 相邻步骤、内容和辅助说明使用场景规定的间距。
- [ ] 状态切换不造成布局跳动，长文本有换行或截断策略。
- [ ] 工作台的分隔条、收起面板和恢复状态都经过验证。

## AI 对话与课程流程

- [ ] 步骤标题为 16px Medium，步骤计数为 16px Regular，状态图标在标题行最右侧。
- [ ] 步骤间 20px；标题到辅助说明 8px；辅助说明到首个内容 12px。
- [ ] 选择题标题为 14px Medium；单元编号在蓝色卡片内水平、垂直居中。
- [ ] 四个步骤完成后进入课程预览，加载图标切换为完成图标。
- [ ] 课程预览提供“开始学习”和“加入学习计划”。

## 白板与视频学习

- [ ] 白板和视频可以在右上角功能区切换，切换后不丢失课节和上下文。
- [ ] 白板画布、AI 学伴、字幕和加入笔记流程可用。
- [ ] 视频、代码和 IDE 三栏默认顺序正确；卡片圆角 12px、间距 8px。
- [ ] 视频代码时间点、复制、AI 解读和置入 IDE 均可操作。
- [ ] IDE 可收起、拖动调宽，并提供键盘等效操作。

## 层级与可访问性

- [ ] 页面内浮层、模态层和全屏流程按统一 z-index 工作。
- [ ] 全屏流程不会被首页 Hero、搜索菜单或导航穿透。
- [ ] 图标按钮有 aria-label，键盘可以完成主要路径，焦点不会被遮挡。
- [ ] 正文和辅助文字保持可读对比度；颜色不是表达状态的唯一方式。
- [ ] 窄屏不出现不可解释的横向滚动，三栏工作台能切换为单列或可收起布局。

## 交付前检查

- [ ] 默认、悬停、选中、加载、完成、失败和返回状态均已查看。
- [ ] 关键流程可以重复进入和退出，页面不会残留旧状态。
- [ ] 链接、资源路径和本地字体加载正常。
- [ ] 只提交本次涉及的文件，不混入临时文件和构建产物。
