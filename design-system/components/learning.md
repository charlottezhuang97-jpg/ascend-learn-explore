# 学习组件

## UnitBadge 与 LessonRow

- 单元编号在蓝色编号卡片内水平和垂直居中；
- 课节序号后必须标注内容类型图标和文字；首版类型为课程、文档、测验、实践；
- 课节标题使用 16px Regular，说明文字使用 14px Regular；
- 课节列表的类型不只依靠颜色表达，图标和文字必须同时存在。

## CodeSnippet

代码片段必须展示时间点、标题、代码预览和操作区。操作区包含复制、AI 解读和置入 IDE；置入后保留代码来源时间点，方便回到视频位置。

## FloatingActionBar

课程预览底部固定悬浮操作面板仅保留“加入学习计划”，并显示已加入状态；“开始学习”属于具体课节或讲次操作，不能在预览页底部重复出现。悬浮面板不能遮挡课程目录和最后一个内容单元。
