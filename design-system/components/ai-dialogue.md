# AI 对话组件

## AIStep

AI 生成页面的大步骤使用连续文档流，不使用大边框卡片。标题行包含步骤标题、`第 x 步，共 4 步` 和状态图标；状态图标始终位于标题行最右侧。

| 区域 | 规格 |
| --- | --- |
| 步骤标题 | 16px、Medium |
| 步骤计数 | 16px、Regular |
| 标题到辅助说明 | 8px |
| 辅助说明 | 16px、Regular、`#000000` 60% |
| 辅助说明到首个内容 | 12px |
| 步骤之间 | 20px |
| 选择题标题 | 14px、Medium |
| 选项卡片 | 300px × 160px，标题 16px，描述 14px |

## 内容顺序

```text
步骤标题／步骤计数／状态
  ↓ 8px
辅助说明
  ↓ 12px
题目、来源列表、大纲或课程预览
```

第一个步骤主要呈现检索资料和来源；第二个步骤让用户回答问题、构思学习路径；第三个步骤承接课程大纲编辑；第四个步骤进入课程预览。第二、三、四步骤不强制套用“步骤状态—技术栈—来源”的三行结构，应根据内容类型呈现真正有用的信息。
