# AI 对话组件

## AIStep

AI 生成页面的大步骤使用连续文档流，不使用大边框卡片。标题行包含步骤标题、`第 x 步｜共 4 步` 和状态图标；状态图标始终位于标题行最右侧。

| 区域 | 规格 |
| --- | --- |
| 步骤标题 | 14px、Regular、`#000000` 60% |
| 步骤计数 | 14px、Regular、`#000000` 60%，文案为“第 x 步｜共 4 步” |
| 标题到辅助说明 | 8px |
| AI 回答描述 | 14px、Regular、`#000000` 60%，与步骤标题一致 |
| 辅助说明 | 14px、Regular、`#000000` 60% |
| 辅助说明到首个内容 | 12px |
| 步骤之间 | 20px |
| 选择题标题 | 16px、Medium |
| 选项卡片 | 300px × 160px，标题 16px，描述 14px |

## 内容顺序

```text
步骤标题／步骤计数／状态
  ↓ 8px
辅助说明
  ↓ 12px
题目、来源列表、大纲或课程预览
```

第一个步骤主要呈现检索资料和来源：前三条来源逐条出现，其余来源收纳于“查看更多资料”。第二个步骤让用户依次回答四题、构思学习路径；题目完成后进入默认全屏的大纲视图，退出后回到对话流中的大纲卡片。确认大纲后进入默认全屏课程预览；课程标题后提供播放入口，退出全屏后回到对话流中的课程预览卡片。第二、三、四步骤不强制套用“步骤状态—技术栈—来源”的三行结构，应根据内容类型呈现真正有用的信息。
