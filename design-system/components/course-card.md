# CourseCard 课程卡片

课程卡片用于让用户判断“这条学习内容是否适合我”，不是课程详情页的缩略版。信息按用户决策顺序呈现。

## 信息层级

### 默认态

1. 课程所属开发类型：CANN、生成式 AI 与大模型、AI 应用与智能体；
2. 适合角色；
3. 典型开发场景；
4. 知识递进路线；
5. 进入课程详情或 AI 规划的入口。

### 悬浮／展开态

1. 学习时长、单元数、讲次数；
2. 实践强度：轻实践、标准实践、强实践；
3. 是否支持 HiDevLab 在线环境；
4. 学完是否可直接参与认证；
5. 学习人数和课程评价。

## 组件规格

| 属性 | 规则 |
| --- | --- |
| 标题 | 16px Medium，最多两行 |
| 描述 | 14px Regular，最多三行 |
| 标签 | 12px 或 14px，必须说明分类、环境、实践或认证 |
| 递进路线 | 用简短知识节点表达学习顺序，不用课程类型代替知识结构 |
| 辅助信息 | 学习人数和评价放在低视觉优先级，不与主要场景抢注意力 |
| 状态 | `default`、`hover`、`selected`、`loading`、`unavailable` |
