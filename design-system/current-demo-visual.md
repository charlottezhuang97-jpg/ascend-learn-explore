# 当前 demo 视觉基线

更新依据：本仓库现行 `index.html`、`course-preview.html`、`learn.html`、`certification-path.html` 及其已加载样式。此文件描述当前产品方向；用户后续提供的新设计稿可覆盖本基线。

## 风格骨架

| 场景 | 现行视觉 | 不再沿用的历史表现 |
| --- | --- | --- |
| 首页发现 | 浅蓝渐变与白色点阵 Hero、独立的浅色大搜索框、黑色主要操作、蓝紫强调；内容楼层以白底和大留白组织 | 搜索框外再垫一层灰蓝底、旧的顶部模式 Tab |
| 课程详情 | 浅灰页面底、白色内容区、清晰的课程信息层级；右侧学习建议卡片轻量呈现 | 过粗过大的侧栏字、与首页不一致的学伴头像 |
| 沉浸学习 | 白色固定框架；顶部课节与工具，中央仅显示当前视频／白板／实验视角，右侧独立学习助手，底部模式栏和语义时间线 | 先显示旧白板／视频框架再脚本覆盖；视频与 IDE 强制并排、下方堆叠多个学伴停靠区 |
| 认证路径 | 浅色点阵画布、蓝色中心路径、侧边章节卡、考试与证书节点；标题随认证目标变化 | 用推理课程章节重复填充算子认证考试节点 |

## 色彩和表面

- 文字：高对比近黑用于标题，灰色用于说明和次级元信息；学习助手和交互选中用蓝紫色。
- 首页 Hero：冷浅蓝渐变、细白点阵，白色粒子聚光交互保留。内容区域以白和极浅灰为基础；黑色用于强行动按钮、浮出的课程／路径／认证胶囊标签。
- 沉浸框架：外框与工具条以白色、极浅边线为主；视频画面可用深色背景；实验 IDE 以当前浅色编辑器为基准，保留蓝色运行与焦点状态。
- 点阵是首页 Hero 和认证路径画布的空间线索，不延伸为每张内容卡的纹理。避免多层背景、嵌套边框和重复阴影。

## 布局和信息层级

- 首页标题下展示“你想学习…，或正在解决…？”提问，学习主题和开发问题以约 5 秒节奏逐字轮换；搜索框下方用透明玻璃质感、黑字的三步测验引导。卡片悬浮有聚焦与相邻卡片轻微让位，不造成大幅跳动。
- 首页搜索框聚焦后，下方展开白色浅玻璃面板：最近搜索、横向推荐提问、快速开始课程与热门课程。输入后切换为匹配卡及搜索建议；匹配卡的“开始学习”按算子、推理、智能体或训练主题直接进入对应课程详情。快捷 `/` 菜单仍独立运行。
- 课程详情从课程目标、学习进度、单元内容进入学习；“学习助手”名称、图标和首屏与首页统一。
- 沉浸学习的视频、白板、实验是同一视角槽的不同内容。右侧助手面板独立于视频字幕、板书和 IDE，不嵌入画面。底部进度条的知识、实践、笔记等节点承载不同语义。
- 情感化情境演示在视频视角使用独立的深色小遥控器，展开后原位显示“提问、停留、暂停”三个状态入口；提示卡沿用学习助手的浅蓝紫表面。遥控器只用于切换演示状态，正式提醒由学习行为触发，不以鼠标静止作为唯一判断。
- 学习助手的课程总结、章节总结、智能摘要、笔记、视频字幕、知识点、测一测保持七项入口与一致的内容状态。输入、回复和上下文在视角切换后持续可见。
- 课程总结沿用智能摘要的时间线卡片样式，按课程章节分卡；章节总结只呈现当前章节的一张卡片。点击字幕时间点时，播放时间和底部语义进度指针同步定位。
- 下滑至课程评价时，完整学习助手收为只显示图标、当前功能与一句说明的小气泡；评价内容完整呈现。回到首屏自动恢复原有助手尺寸与内容。
- 白板讲解文字逐字出现，相关示意图与表格在对应解释完成后出现；文字始终可划选。划词旁提供“有疑问”和“记笔记”，前者进入学伴对话并给出短问题气泡，后者保留为学习笔记。助手拖放按释放点相对视口中心的斜向分区判定，左侧成为左栏，底部收成居中的浅色提问框；底部状态下视频、白板或 IDE 主内容占满原助手右栏。移动不足 50px 不改变布局。
- 视频暂停和“卡住了吗”提示共用紫色助手图标、浅蓝紫表面、黑色主要操作、文字次要操作和“不再提示”选项。
- 实验 IDE 复用浅色 HiDevLab 框架：环境状态、文件树、编辑器、终端／输出与运行控制；提示及代码置入显示在当前实验上下文。
- 实验教练是围绕一个明确实验目标创建的学习 Agent。创建时只收集名称、标识和目标；后续将 MindIE 文本生成实验拆为可追踪任务，并从任务进入现有 IDE 七步引导。原型手动标记进度必须明确区别于真实环境验证。
