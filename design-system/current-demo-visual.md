## 色彩和表面

- 文字：高对比近黑用于标题，灰色用于说明和次级元信息；学习助手和交互选中用蓝紫色。
- 首页 Hero：冷浅蓝渐变与白色方形粒子。首屏背景里的点阵飞鸟沿左下至右上飞行，20 秒一轮；方形粒子在鼠标靠近时原位增亮，部分粒子在标题与搜索框附近独立闪烁。背景层不拦截输入，并响应系统的减弱动态效果设置。内容区域以白和极浅灰为基础；黑色用于强行动按钮、浮出的课程／路径／认证胶囊标签。
- 首页搜索框右上沿可放鲲鹏小人：默认趴在输入框边缘，悬浮切换为完整的挥手姿态；小人仅作装饰，不阻挡输入、标题或搜索结果。
- 首页社区经验贡献楼层：浅蓝大卡片承载“你的经验，值得被整个社区记住”；周围用浅玻璃代码片段卡、圆形头像与博客预览卡，以及简短状态标签展示真实贡献形式。状态标签与博客卡、代码卡与底部标签之间各点缀一至两个小 emoji，中央标题区域保持清晰。卡片下方是约 60px 高、同宽且同圆角的浅蓝兑换横幅与黑色主要按钮；窄屏时横幅文字换行，按钮始终可触达。
- 沉浸框架：外框与工具条以白色、极浅边线为主；视频画面可用深色背景；实验 IDE 以当前浅色编辑器为基准，保留蓝色运行与焦点状态。
- 点阵是首页 Hero 和认证路径画布的空间线索，不延伸为每张内容卡的纹理。避免多层背景、嵌套边框和重复阴影。

## 布局和信息层级

- 首页标题下展示“你想学习…，或正在解决…？”提问，学习主题和开发问题以约 5 秒节奏逐字轮换；搜索框下方用透明玻璃质感、黑字的三步测验引导。搜索框右上方的小人约为原尺寸的一半，挥手姿态停在框的上沿。首屏三张叠放卡片在入场时弹跳一次，边缘有浅色玻璃描边；悬浮仅将当前卡片置于最上层，不放大或推开邻卡。
- 首页搜索框聚焦后，下方展开白色浅玻璃面板：推荐提问横向排列，时钟图标可将面板切换成最近搜索视图，右上角关闭后回到推荐提问；底部始终是可点击“开启”的三步测验引导。输入后切换为匹配卡及搜索建议；匹配卡的“开始学习”按算子、推理、智能体或训练主题直接进入对应课程详情。快捷 `/` 菜单仍独立运行。
- 首页首次进入时，原来三张继续学习卡片的位置呈现“第一个小任务”：独立的 HiDevLab 学习视窗，左侧为文件、代码编辑和终端，右侧为任务引导与图像结果。任务完成后该位置恢复三张继续学习卡片，并可重新体验；“按照开发场景学习”楼层始终展示课程链路，完成任务后精选第一项接续 Add 算子的正式学习。浏览器预览与真实 NPU 运行分别标注。
- 课程详情从课程目标、学习进度、单元内容进入学习；“学习助手”名称、图标和首屏与首页统一。
- 沉浸学习的视频、白板、实验是同一视角槽的不同内容。右侧助手面板独立于视频字幕、板书和 IDE，不嵌入画面。底部进度条的知识、实践、笔记等节点承载不同语义。
- 情感化情境演示在视频视角使用独立的深色小遥控器，展开后原位显示“提问、停留、暂停”三个状态入口；提示卡沿用学习助手的浅蓝紫表面。遥控器只用于切换演示状态，正式提醒由学习行为触发，不以鼠标静止作为唯一判断。
- 学习助手的课程总结、章节总结、智能摘要、笔记、视频字幕、知识点、测一测保持七项入口与一致的内容状态。输入、回复和上下文在视角切换后持续可见。
- 课程总结沿用智能摘要的时间线卡片样式，按课程章节分卡；章节总结只呈现当前章节的一张卡片。点击字幕时间点时，播放时间和底部语义进度指针同步定位。
- 下滑至课程评价时，完整学习助手收为只显示图标、当前功能与一句说明的小气泡；评价内容完整呈现。回到首屏自动恢复原有助手尺寸与内容。
- 白板讲解文字逐字出现，三栏文字全部完成后才显示示意图与表格；三栏内容按自然高度向下排布，由整个白板画布滚动，左栏不另设固定高度或独立滚动。示意图排在左栏全部讲解文字之后，不覆盖段落。文字始终可划选。划词旁提供“有疑问”和“记笔记”，前者进入学伴对话并给出短问题气泡，后者保留为学习笔记。助手拖放按释放点相对视口中心的斜向分区判定，左侧成为左栏，底部收成居中的浅色提问框；底部状态下视频、白板或 IDE 主内容占满原助手右栏。移动不足 50px 不改变布局。
- 视频暂停和“卡住了吗”提示共用紫色助手图标、浅蓝紫表面、黑色主要操作、文字次要操作和“不再提示”选项。
- 实验 IDE 复用浅色 HiDevLab 框架：环境状态、文件树、编辑器、终端／输出与运行控制；提示及代码置入显示在当前实验上下文。
- 实验教练是围绕一个明确实验目标创建的学习 Agent。创建时只收集名称、标识和目标；后续将 MindIE 文本生成实验拆为可追踪任务，并从任务进入现有 IDE 七步引导。原型手动标记进度必须明确区别于真实环境验证。
