# 视频学习工作台模式

视频学习采用工作台，而不是嵌入白板画布。桌面端的核心区域固定为“视频讲解 + IDE 实践”，代码、课程资源、任务与 AI 学伴进入下方左右两个辅助停靠区。卡片间距 8px，圆角 12px。

- 视频区固定在左上，进度条标记重要知识点、代码示例和实践节点；
- IDE 固定在右上，通过分隔条与视频区共同调宽，始终保留编辑和运行上下文；
- 代码、课程资源、任务与 AI 学伴属于辅助面板，可拖拽到左侧或右侧停靠区；
- 所有可拖拽操作都提供“移到左侧／右侧”按钮，布局会被记忆，并可一键恢复默认布局；
- IDE 采用在线开发工作台结构，包含环境状态、资源管理器、编辑器、输出／终端和状态栏；
- 顶部沿用白板的关闭、课节标题、白板／视频切换和辅助工具。

视频、代码和 IDE 是同一学习任务的连续上下文。代码片段和播放位置必须保持双向可追踪，置入 IDE 后仍保留来源时间点。

## 区域结构与组件

| 区域 | 组件 | 默认行为 |
| --- | --- | --- |
| 顶部 | `LessonTitle`、`ModeToggle`、`ToolBar` | 固定显示课节、白板／视频切换和辅助功能 |
| 左上 | `VideoPlayer`、`VideoTimeline` | 固定区域，播放时间是主上下文 |
| 右上 | `IDEWorkspace` | 固定区域，展示环境、文件、编辑器、输出和状态 |
| 分隔区 | `ResizeHandle` | 鼠标拖动和左右方向键调整视频／IDE 宽度 |
| 左下辅助区 | `DockZone`、`CodeSnippetList` | 默认放视频代码，可接收其他辅助面板 |
| 右下辅助区 | `DockZone`、`ResourceTabs`、`TaskCompanion` | 默认放课程资源和任务／学伴，可接收其他辅助面板 |
| 顶部 | `ResetLayout` | 清除已保存的宽度和面板位置，恢复默认布局 |

## 交互序列

1. 视频播放时同步当前时间点和代码片段；
2. 点击代码时间点，视频跳到对应位置并将片段置为 selected；
3. 复制只反馈成功，不离开当前工作台；
4. AI 解读在代码片段内展开，不能推动其他区域产生不可预测跳动；
5. 置入 IDE 后写入当前编辑器，并保留来源时间点；
6. IDE 运行后在 IDE 内反馈问题、输出、调试控制台或终端结果；
7. 拖动辅助面板到另一停靠区，系统保存位置；按钮操作产生同样结果；
8. 调整视频与 IDE 的分隔条后保存宽度；“恢复默认布局”同时恢复面板位置和宽度。

## 状态表

| 区域 | 状态 | 反馈 |
| --- | --- | --- |
| 视频 | `idle` / `playing` / `paused` / `buffering` / `completed` | 播放按钮、时间、进度和字幕保持稳定 |
| 时间点 | `none` / `selected` / `code-selected` | 视频和代码高亮保持双向同步 |
| 代码 | `loading` / `ready` / `explaining` / `copied` / `inserted` | 操作结果就地反馈，保留来源 |
| IDE | `connected` / `editing` / `running` / `success` / `error` | 环境连接、运行状态与输出区域对应 |
| 资源 Tab | `selected` / `empty` / `loading` | 代码、错误码、测验和文档不混合展示 |
| 辅助面板 | `docked-left` / `docked-right` / `dragging` | 停靠区高亮，放置后保存布局 |

## 验收点

- 视频和 IDE 固定为核心区，不允许被辅助面板替换或拖走；
- 卡片圆角统一 12px，卡片间距统一 8px；
- 视频时间点、代码片段和 IDE 来源可以相互追踪；
- 辅助面板可拖到左右停靠区，并提供按钮等效操作和恢复默认布局；
- 拖动分隔条后不出现横向溢出，键盘操作与鼠标操作结果一致；
- 窄屏自动变成视频 → IDE → 辅助面板的单列顺序。
