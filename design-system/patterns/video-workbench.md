# 视频学习工作台模式

视频学习采用浅色工作台，而不是嵌入白板画布。桌面端按“视频与资源、随视频联动的代码、IDE 实践区”分为三个区域，卡片间距 8px，圆角 12px。

- 视频区默认占据最大可用宽度，进度条标记重要知识点、代码示例和实践节点；
- 代码区位于中间，以时间点定位播放位置，支持复制、AI 解读和置入 IDE；
- IDE 位于右侧，可收起并通过拖动分隔条调整宽度；
- 视频辅助页签包括代码全览、常见错误码、随堂测试和相关文档；
- 顶部沿用白板的关闭、课节标题、白板／视频切换和辅助工具。

视频、代码和 IDE 是同一学习任务的三个视图。代码片段和播放位置必须保持双向可追踪，置入 IDE 后仍保留来源时间点。

## 区域结构与组件

| 区域 | 组件 | 默认行为 |
| --- | --- | --- |
| 顶部 | `LessonTitle`、`ModeToggle`、`ToolBar` | 固定显示课节、白板／视频切换和辅助功能 |
| 左侧 | `VideoPlayer`、`VideoTimeline`、`ResourceTabs` | 默认最大宽度，播放时间是主上下文 |
| 中间 | `CodeSnippetList`、`CodeSnippet` | 跟随时间点选中，支持复制、解读、置入 |
| 右侧 | `IDEWorkspace` | 默认展开，可收起、拖动调宽、运行代码 |
| 分隔区 | `ResizeHandle` | 鼠标拖动和左右方向键调整宽度 |

## 交互序列

1. 视频播放时同步当前时间点和代码片段；
2. 点击代码时间点，视频跳到对应位置并将片段置为 selected；
3. 复制只反馈成功，不离开当前工作台；
4. AI 解读在代码片段内展开，不能推动其他区域产生不可预测跳动；
5. 置入 IDE 后写入当前编辑器，并保留来源时间点；
6. IDE 运行后在 IDE 内反馈问题、输出、调试控制台或终端结果；
7. 收起 IDE 后，视频和代码区域平滑填充剩余空间；重新展开恢复上次宽度。

## 状态表

| 区域 | 状态 | 反馈 |
| --- | --- | --- |
| 视频 | `idle` / `playing` / `paused` / `buffering` / `completed` | 播放按钮、时间、进度和字幕保持稳定 |
| 时间点 | `none` / `selected` / `code-selected` | 视频和代码高亮保持双向同步 |
| 代码 | `loading` / `ready` / `explaining` / `copied` / `inserted` | 操作结果就地反馈，保留来源 |
| IDE | `expanded` / `collapsed` / `editing` / `running` / `success` / `error` | 运行状态与输出区域对应 |
| 资源 Tab | `selected` / `empty` / `loading` | 代码、错误码、测验和文档不混合展示 |

## 验收点

- 三栏顺序固定为视频、代码、IDE；IDE 默认位于右侧并可收起；
- 卡片圆角统一 12px，卡片间距统一 8px；
- 视频时间点、代码片段和 IDE 来源可以相互追踪；
- 拖动分隔条后不出现横向溢出，键盘操作与鼠标操作结果一致；
- 窄屏自动变成单列或按视频 → 代码 → IDE 顺序收起展开。
