# 白板学习模式

白板是默认学习形式，适合建立概念直觉和跟随讲解推进。页面由讲课画布和 AI 学伴组成：

- 左上：关闭课程和课节标题；
- 右上：白板／视频切换、缩放、翻页、下载、AI 学伴和设置；
- 画布：板书、课堂要点和字幕；
- 右侧：默认展开的 AI 学伴，包含对话和我的笔记；
- 画布文字：长按选词后可加入我的笔记。

板书页码、缩放比例、当前课堂要点、字幕和笔记数量都是可恢复状态。画布内容不得被 AI 学伴覆盖，辅助面板收起后应保留内容区宽度。

## 区域结构与组件

| 区域 | 组件 | 主要操作 |
| --- | --- | --- |
| 顶部左侧 | `IconButton`、`LessonTitle` | 关闭课程、查看课节 |
| 顶部右侧 | `ModeToggle`、`ToolBar` | 白板／视频、缩放、翻页、下载、AI 学伴、设置 |
| 画布 | `BoardCanvas`、`LessonSubtitle`、`LearningAnchor` | 阅读板书、长按选词、翻页、跳转关联文档或视频时间点 |
| 画布底部 | `CaptionBar` | 查看当前讲解字幕 |
| 右侧 | `AICompanion`、`CompanionTabs` | 提问、查看我的笔记、收起 |
| 实践区 | `IDEWorkbench`、`ErrorSummary`、`FixProposal` | 运行代码、定位错误、查找依据、确认 AI 修复 |
| 关联资料 | `DocumentPanel`、`MediaTimeline` | 阅读对应文档、按时间点切换视频、返回原板书 |

## 交互序列

1. 课程预览点击“开始学习”后打开学习形式选择；
2. 选择白板后默认加载第 1 课节和第 1 页板书；
3. 翻页、缩放和字幕推进只更新画布内容，不改变页面结构；
4. 长按文字后出现“加入我的笔记”，保存后更新 AI 学伴笔记数量；
5. AI 学伴提问自动带入当前课节、页码和选中文本上下文；
6. 切换视频后保留课节和学习进度，返回白板恢复原页码。

## IDE 报错与 AI 主动修复

代码运行失败后，错误反馈必须靠近 IDE 终端，并且同时包含：错误码、发生位置、通俗原因和下一步操作。不能只用红色或一次性浮层表达失败。

用户至少可以选择以下三条路径：

1. “定位代码”：聚焦并选中发生错误的代码行；
2. “查看依据”：打开官方文档章节、关联板书以及对应视频时间点；
3. “AI 建议修复”：生成原因说明和修改前后差异。

AI 可以在运行失败后主动提示能够协助，但不得静默改写代码。修复流程为“生成建议 → 展示 diff 与依据 → 用户确认应用 → 重新运行验证”。应用修复后保留撤销能力，且不得把“已应用”表述为“已修复”；只有重新运行成功后才能标记问题解决。

## 文档、板书与视频的对应关系

同一知识点使用统一的 `LearningAnchor`：

| 字段 | 示例 | 用途 |
| --- | --- | --- |
| `lessonId` | `lesson-02` | 保持课节上下文 |
| `boardPage` | `board-01` | 返回原板书页 |
| `videoRange` | `03:20–05:45` | 标记该板书覆盖的视频区间 |
| `documentSection` | `guide-2.3` | 定位文档章节 |
| `codeSnippetId` | `copyout-basic` | 关联 IDE 代码片段 |

白板顶部应展示关联视频区间和文档章节。点击视频时间点进入对应播放位置，不自动播放；返回白板时恢复原页码、缩放、字幕位置和 IDE 代码。文档默认以同屏辅助面板或抽屉呈现，并提供打开原文入口，避免为查定义而丢失学习现场。

视频时间轴可以标出与板书一致的三个节点，例如 03:20 输入搬运、04:10 向量计算、05:05 结果写回。板书到视频是区间映射，文档到板书是章节映射，二者都必须支持反向返回。

## 状态表

| 区域 | 状态 | 反馈 |
| --- | --- | --- |
| 画布 | `loading` / `ready` / `page-changing` | 保留画布尺寸，显示页码和加载反馈 |
| 选词 | `idle` / `selected` / `saved` | 选中区域和笔记保存结果可见 |
| 字幕 | `playing` / `paused` / `completed` | 当前句高亮，完成后允许回看 |
| AI 学伴 | `open` / `collapsed` / `answering` / `notes-empty` | 收起不丢上下文，回答显示来源 |
| IDE 运行 | `idle` / `running` / `failed` / `fix-proposed` / `fix-applied` / `verified` | 失败可定位，建议有差异，应用后要求重新验证 |
| 关联资料 | `board` / `document` / `video-seek` / `returning` | 切换媒体时保留统一学习锚点和返回位置 |

## 验收点

- 长按和键盘操作不会误触关闭课程；
- 右侧 AI 学伴收起后画布占满剩余空间；
- 画布、字幕和 AI 学伴之间保持 20px 的主要间距节奏；
- 颜色不是课堂要点、选词或完成状态的唯一表达方式。
- IDE 报错后键盘焦点进入错误摘要，错误摘要提供可执行恢复路径；
- AI 修复必须在用户确认后应用，应用前可查看依据，应用后可撤销并重新运行；
- 板书、视频和文档之间的跳转可双向返回，不丢失板书页码、视频时间点或代码编辑状态。
