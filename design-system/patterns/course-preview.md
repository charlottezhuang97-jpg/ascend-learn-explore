# 课程预览模式

课程预览是从 AI 生成或课程详情进入沉浸学习前的确认页。它展示课程目标、适合人群、知识递进、单元和课节、学习成本、环境和来源。

信息顺序优先回答：

1. 这门课是否适合当前用户；
2. 学完能够完成什么开发任务；
3. 需要投入多少时间和实践成本；
4. 内容来自哪里、是否可以直接开始。

单元编号卡片内的文字必须居中；课节标题后标注课程、文档、测验或实践类型。底部悬浮操作栏提供“开始学习”和“加入学习计划”。

## 讲次卡片交互

- 讲次卡片使用 12px 圆角和页面默认卡片边框；课程、文档、测验、实践均在课节序号后以图标与文字标注。
- 悬浮或键盘聚焦时，在卡片右侧显现继续学习、预览课节和加入计划操作；操作区在卡片预留宽度内展开，卡片高度与页面布局不得变化。
- 窄屏不依赖悬浮，右侧操作区转为卡片内的常驻操作。
