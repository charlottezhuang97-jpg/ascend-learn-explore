# AI 对话模式

## 用户任务

用户从首页搜索进入后，AI 在同一条全屏对话流中完成目标确认、构思学习路径、组织课程大纲和课程预览。

## 信息流

```text
用户问题
  → 正在搜索相关资料｜第 1 步，共 4 步
  → 构思学习路径｜第 2 步，共 4 步
  → 打造课程｜第 3 步，共 4 步
  → 完善课程｜第 4 步，共 4 步
```

大步骤之间保持 20px；标题到辅助说明 8px；辅助说明到首个内容 12px。步骤标题使用 16px Medium，步骤计数使用 16px Regular，完成和加载图标在标题行最右侧。

## 进入与退出

- 搜索框支持快捷标签、`Tab` 切换预置目标、`Enter` 开始搜索；
- 完成四个步骤后进入课程预览；
- 课程预览可开始学习、加入学习计划或返回修改大纲；
- `Escape` 关闭弹窗或返回上一层，并恢复触发入口焦点。

## 区域结构

| 区域 | 内容 | 是否固定 |
| --- | --- | --- |
| 顶部 | 返回首页、用户原始问题、当前流程标题 | 固定 |
| 主对话流 | 用户问题、四个大步骤和 AI 回答 | 滚动 |
| 步骤标题行 | 步骤标题、步骤计数、loading/completed 图标 | 随步骤内容出现 |
| 底部操作 | 跳过、继续、返回修改或开始学习 | 随当前步骤变化 |

## 组件组合

`UserPrompt` → `AIStep` → `QuestionOption` / `SourceList` / `OutlineCanvas` / `CoursePreview` → `FloatingActionBar`。

每一步只呈现当前任务需要的内容。第一步可以展开资料来源和“更多”；第二步呈现问答选项；第三步呈现可编辑大纲；第四步呈现课程预览，不重复输出右侧已经展示的大纲内容。

## 状态与恢复

| 状态 | 触发 | 页面反馈 |
| --- | --- | --- |
| `searching` | 正在检索资料 | 标题行 loading，来源列表逐条出现 |
| `answering` | 等待用户回答 | 当前问题可操作，后续步骤保持占位 |
| `generating` | AI 正在组织大纲或课程 | 保留回答容器尺寸，允许取消或继续等待 |
| `editable` | 大纲或课程可修改 | 节点、单元和课节显示编辑入口 |
| `completed` | 四步完成 | 所有步骤使用完成图标，进入课程预览 |
| `interrupted` | 用户离开或网络中断 | 恢复上次步骤和已确认答案 |

## 数据连接

输入目标 → 用户画像 → 资料来源 → 已确认答案 → 课程大纲 → 课程预览 → 学习计划。每一步都保留来源和版本，AI 输出不得伪装成已接入的实时资料。
