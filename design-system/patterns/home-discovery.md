# 首页发现模式

## 用户任务

用户进入首页后，先表达学习目标或开发问题，再判断适合自己的开发场景和学习起点。首页还承担公共榜样发现和开发者激励，但不承载个人成长详情。

## 区域结构

```text
顶部导航
  → Hero：自然语言搜索／快捷目标／学习方向测试
  → 继续学习：恢复上次任务
  → 开发场景：角色、典型场景、知识递进、学习成本
  → 开发者成长与贡献：学习成长、实战突破、社区共建摘要
```

## 组件组合

- `SearchInput`：placeholder 为“今天你想学点什么？使用/获取快捷选项”；支持 `/` 聚焦、Tab 切换预置目标、Enter 提交；
- `Chip`：新手入门、模型训练、推理部署、算子开发、故障排查等快捷目标；
- `CourseCard`：默认先呈现开发类型、适合角色、典型场景和知识路线，悬浮后再呈现学习成本；
- `GrowthBoard`：三个公共榜单页签，卡片呈现用户名、阶段、行为和结果证据。

## 交互序列

1. 空输入时展示提示和快捷入口；
2. 获得焦点后快捷菜单保持在页面最高的首页局部层级；
3. Enter 后进入全屏 AI 对话，首页全部元素被覆盖；
4. 点击开发场景课程卡进入对应课程预览；“查看更多课程”中的课程卡也遵循相同跳转规则；
5. 点击榜单记录进入完整榜单或代表性案例，不在首页展开个人成长卡。

## 状态与验收

- 搜索：`empty`、`focused`、`suggestions-open`、`typing`、`submitting`、`error`；
- 场景卡：`default`、`hover`、`filtered`、`empty-result`；
- 榜单：`loading`、`loaded`、`tab-selected`、`empty`；
- 验收：首页 Hero、搜索菜单和场景卡不能穿透全屏 AI 流程；窄屏时场景卡与榜单可以单列排列。
