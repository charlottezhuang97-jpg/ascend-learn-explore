# 主页布局规范（layout-home）

> 来源：Figma 文件「社区1.0低保真」，节点 `120:205`（帧名：开发者学习中心-选中在cann）
> 提取日期：2026-08-31
>
> **节点归属说明**：该节点内容为「开发者学习中心（Developer Learning Center）」页面，顶部全局导航中「学习」处于选中态。内容结构（Banner、简介、学习路径选择器、课程卡片网格、CTA）符合站点"主页/落地页"的典型形态，本文按用户要求将其作为主页布局处理。若后续发现站点另有独立的顶层首页节点，请对照复核。
>
> 本文件仅描述布局规则（栅格、排布、间距、对齐），不重复颜色/字体等数值——引用时请使用 [`design-tokens.json`](../tokens/design-tokens.json) 中的 token。
>
> **局限性**：该 Figma 文件为低保真线框图（低保真），以下栅格与间距均为对该节点的**实测观察值**，非官方发布的栅格规范，建议与视觉定稿版本复核后再固化到工程规范中。

## 1. 画布与栅格

| 项 | 值 |
|---|---|
| 设计画布宽度 | 1920px（桌面端） |
| 画布总高度 | 2503px |
| 主内容容器宽度 | 1488px，水平居中，左右各留白 216px |
| 通栏区块宽度 | 约 1896–1930px（近似撑满画布，仅左右各留 ~10–34px） |

**规则**：页面存在两种宽度容器——

- **限宽内容容器**（1488px）：用于导航、标题文字、学习路径选择器等以文字/交互为主的区块，水平居中于画布。
- **通栏容器**（~1896–1930px）：用于 Banner 主视觉、装饰性配图等视觉强区块，跳出限宽容器做近似撑满处理，仅保留极小的安全边距。

1488px 可视为 12 列栅格的内容区宽度（列宽 + 间距按 1488/12 反推，线框图未标注具体列线，工程侧建栅格时建议按此宽度反推列宽/gutter）。

## 2. 页面区块与纵向排布

页面为单列纵向堆叠结构，从上到下依次为：

1. **顶部导航**（Navigation，高 64px）—— 位于限宽容器内，横向排列，见第 4 节
2. **Banner 主视觉**（Group 4，约 1930×822）—— 通栏，含玻璃拟态（glassmorphism）风格装饰图形
3. **标题与简介**（Group 1，约 900×170）—— 「开发者学习中心（DLC）」标题 + 副标题，限宽容器内
4. **辅助信息条**（Group 5，约 1488×56）
5. **说明区块**（Frame 2，约 1896×328）—— 二级标题 + 正文说明
6. **学习路径选择器**（Frame 5，约 1896×422，纵向 auto-layout）
7. **场景选择标题**（Group 12，约 1896×80）—— 「选择一个场景，为你提供一个最合适的学习路径」
8. **课程卡片网格**（Group 13，约 1488×564）—— 详见第 3 节
9. **底部说明/CTA**（"若想访问更多路径，可点击查看所有" 文字 + 通栏配图 image 9，约 1922×381）

区块间垂直间距无统一常量（线框图区块间距在 ~30–100px 不等，视内容量而定），但均遵循"内容区块限宽 1488 居中 + 视觉区块通栏"的交替节奏。

## 3. 课程卡片网格

课程卡片区（Group 13 内的 Group 19/20/21/22）采用 **2 列 × 2 行** 网格：

| 项 | 值 |
|---|---|
| 单卡尺寸 | 700 × 160 |
| 列间距（水平 gap） | 28px |
| 行间距（垂直 gap） | 24px |
| 网格总宽度 | 1488px（= 700×2 + 28），与限宽内容容器等宽 |

网格内每张卡片结构一致：背景图/图标区 + 标题文本 + 描述文本 + 底部标签组（Group 17）+ 操作区（Frame 10），卡片内部未见 auto-layout 内边距标注，建议工程实现时参照 `design-tokens.json` 中 `component.card.padding-default`（0, 0, 20, 20）。

## 4. 顶部导航对齐规则

- 导航容器高度固定 64px，横向排列，item 间距 32px（token: `component.nav.link.itemSpacing`）
- 各导航链接文字统一使用 `padding-bottom: 20px` 实现跨不同文字长度的**基线对齐**（而非居中对齐）
- 默认态文字色 `color.text.primary`（#000000），选中态（如"学习"）切换为 `color.brand.red-dark`（#C7000B）
- 导航条目顺序：开发者 / 主页 / 开发 / 文档 / 活动 / 学习（选中） / 论坛 / 博客 / 开发者计划

## 5. 对齐方式总结

- **水平**：限宽区块统一以画布中心线对齐（1488px 容器居中于 1920px 画布）；通栏区块左对齐画布边缘（近似撑满）
- **垂直**：全部区块自上而下顺序堆叠，无并列多栏（除课程卡片网格内部的 2×2 排列外）
- **卡片网格内部**：横纵均为等宽等距网格对齐，非瀑布流/错落布局

## 6. 视觉风格提示（非布局数值，供设计侧参考）

Banner 与课程卡片的装饰性图层命名中包含"玻璃""3D玻璃拟态"等描述（对应 AI 生图工具即梦/Jimeng 的生成记录），提示该页面视觉基调为**玻璃拟态（glassmorphism）风格**的半透明质感装饰图形，工程实现装饰层时可作为风格线索，但不属于本文件的布局数值范畴。
