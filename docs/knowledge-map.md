# 算子学习目标 → 知识图谱

分支：知识地图。基于本地 main（a7359b8），在独立工作目录开发，保留原 main 工作区的未提交内容。

## 入口与行为

- 首页输入「我要学习算子开发」，直接进入以图谱为主体的回答页。
- 首页测一测选择算子开发方向，完成初始探索后进入同一图谱。
- `knowledge-map.html` 是共享图谱的独立入口。
- 左侧提供 CANN、生成式 AI、智能体三个场景入口，右侧只渲染选中场景的节点与关联线。默认 CANN；其他场景仅从侧栏切换显示。
- 展开 AscendC 路径，显示四门课程。路径使用线条底纹，课程使用线性课程图标。
- 点击课程打开右侧详情，目录按模块展开或收起；关联课程在抽屉内切换。
- 适配视图只适配当前场景；重置视图恢复当前场景的初始缩放与位置。支持缩放、水平及纵向滚动。
- 抽屉支持键盘循环、Escape 关闭及焦点恢复。其他学习方向保留原有流程。

## 内容边界

当前图谱为设计原型的固定示例，不是实际 AI 生成结果。四个课程名来自需求；描述与目录是用于评审的示意内容，需要与正式课源对齐。抽屉底部「查看完整学习路径」进入现有算子路径预览，不冒充四门课程各自的学习页面。

## 验证

通过浏览器实测搜索入口、测一测入口、路径展开收起、四课程详情、目录展开、关联课程切换、关闭后焦点恢复、全图/聚焦/缩放、移动端抽屉和返回首页。新增 JavaScript 通过语法检查。

## 路径汇入布局

三个场景均改为路径在左、领域在右的单侧曲线布局。CANN 的四条路径共同连接到 CANN；四门课程位于 AscendC 路径的左侧。应用/算子调优保留为四条路径的虚线共同关联，不改变领域、路径与课程的层级语义。保留既有蓝色选中态、路径底纹、课程图标与详情抽屉。

## 编辑学习图谱

- 右上角「编辑课程」进入草稿状态，课程卡片出现移除入口。
- 「从课程库添加课程」打开选择面板，按 CANN、生成式 AI、智能体切换来源，支持搜索、选择归属路径与多选添加。
- 来源复用 `course-preview.js` 中的 `AscendCourseCatalog`，并保留需求指定的四门 AscendC 课程。课程标题、描述、目录及预览链接由同一来源读取，不另行生成虚构课程。
- 同一路径中已有课程禁用重复添加；不同场景的课程不能写入错误场景的路径。
- 每个场景一次展开一条路径的课程，其他路径仍可切换；路径课程数与连线随编辑同步更新。
- 完成编辑写入当前浏览器 localStorage；取消恢复整个编辑会话开始时的数据。浏览器存储不可用时提示只保留在当前页面，不宣称已持久保存。
- 验证：跨场景添加、目录详情、取消恢复、刷新后保留、重复添加禁用、移除、搜索无结果、嵌入回答页入口，以及 390px 手机弹窗布局。
