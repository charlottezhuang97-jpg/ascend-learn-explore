# 前端还原与交付规范

本文件是前端实现入口；设计值和场景规则不在这里重复定义，而是引用五层设计系统。实现新页面前，先阅读 [`design-system/README.md`](../design-system/README.md)，再按页面所属场景读取对应 pattern。

## 实现顺序

1. 从用户任务确定页面场景：发现、AI 对话、课程预览、白板学习、视频工作台或成长反馈。
2. 列出需要的组件，优先复用 [`design-system/components/`](../design-system/components/README.md) 中的组件。
3. 读取对应模式的进入、退出、布局、状态和连接关系。
4. 使用三层 Token，不在业务页面中硬编码新的颜色、字号、圆角、阴影或层级。
5. 补齐默认、悬停、聚焦、选中、加载、完成、失败和恢复状态。
6. 按 [`design-system/acceptance.md`](../design-system/acceptance.md) 完成桌面端、窄屏、鼠标和键盘验收。

## 页面层级

| 层级 | 用途 | 统一要求 |
| --- | --- | --- |
| 页面内容 | 楼层、卡片、导航 | 使用默认文档流和局部布局 |
| 页面内浮层 | 搜索快捷菜单、下拉选择、提示 | 父容器不能裁切；关闭后恢复焦点 |
| 模态层 | 三步测验、确认弹窗 | 遮住背景并阻止背景交互 |
| 全屏流程层 | AI 学习方案、课程预览、沉浸学习 | `position: fixed; inset: 0`，层级高于首页所有后代 |

全屏流程不能被首页 Hero、搜索快捷菜单或导航穿透。Enter 进入全屏流程后，首页元素必须完全隐藏；关闭后才恢复首页交互。

## AI 对话实现约束

- 大步骤使用连续文档流，不使用大边框卡片；
- 步骤标题 16px Medium，步骤计数 16px Regular，状态图标在标题行最右侧；
- 步骤之间 20px；标题到辅助说明 8px；辅助说明到首个内容 12px；
- 选择题标题 14px Medium；选项卡片 300px × 160px，标题 16px、描述 14px；
- 四个步骤完成后 loading 切换为 completed，并进入课程预览；
- 课程预览底部悬浮操作栏提供“开始学习”和“加入学习计划”。

详细组件规格见 [`design-system/components/ai-dialogue.md`](../design-system/components/ai-dialogue.md)，状态见 [`design-system/states.md`](../design-system/states.md)。

## 沉浸式学习实现约束

- 白板和视频是同一课节的两种视图，切换入口固定在右上角功能区；
- 白板由讲课画布和默认展开的 AI 学伴组成，画布支持长按选词加入笔记；
- 视频使用浅色三栏工作台：视频、随视频联动的代码、可收起 IDE；
- 视频工作台卡片圆角 12px、间距 8px，代码时间点和视频播放位置可相互定位；
- 视频代码支持复制、AI 解读和置入 IDE，IDE 支持运行、结果反馈和拖动调宽；
- 分隔条必须提供键盘方向键等效操作，窄屏改为可收起或单列布局。

详细模式见 [`design-system/patterns/whiteboard-learning.md`](../design-system/patterns/whiteboard-learning.md) 和 [`video-workbench.md`](../design-system/patterns/video-workbench.md)。

## 交付要求

- 只提交本次涉及的页面、样式、脚本、设计系统文件和必要资源；
- 不提交临时截图、构建产物或本地调试文件；
- README、页面链接和设计系统引用保持一致；
- 任何新视觉语言先走预览门禁，得到确认后再吸收到设计系统。
