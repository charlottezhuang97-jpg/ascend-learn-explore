# 1030 · MindIE 七步引导演示

依据已确认的 [实验工作流评审](auxiliary/mindie-agent-workflow-review.md) 和实验手册 §2.2。仅更新 1030 预览，不替换正式版。

## 入口与边界

- 页面：`learn-1030.html?course=mindie&mode=ide&guide=open`。
- IDE 的“7步实验引导”或学伴的“完整7步引导”也可进入、恢复当前记录。
- 无主机连接、Shell 执行器、真实请求或实时 AI；所有回显和检查均明确为演示。
- 账号、仓库权限、网页下载和上传需用户在外部安全界面完成，不收集凭据。

## 7 个主步骤 / 25 个子任务

| 步骤 | 子任务 | 必要确认与结果 |
| --- | --- | --- |
| 1 环境准备 | 选主机；NPU 查询；Docker 查询 | 两条只读查询一次授权；健康状态 / Docker 表头 |
| 2 下载模型权重 | 选准备方式；网页下载；上传服务器；检查文件 | 下载上传由用户确认；已有服务器文件分支标记跳过；缺分片不通过 |
| 3 获取 MindIE 镜像 | 设备和镜像；权限；安全登录；拉取 / 复用 | 拉取需权限及外部登录确认；历史镜像版本不是最新推荐 |
| 4 启动容器 | 前置检查；参数权限；创建 / 复用验证 | privileged 与主机网络分别确认；同名冲突不自动删除 |
| 5 模型推理配置 | 进入容器；五条 source；配置差异；备份合并检查 | 初始化、配置两次授权；设备映射和非 HTTPS 单独确认；只展示 JSON 字段片段 |
| 6 启动 MindIE 服务 | 日志端口计划；后台启动；证据核对；停止观察 | 新日志防覆盖；覆盖单独确认；Ctrl+C 只退出 tail，不停止服务 |
| 7 推理交互 | 提示词 / 生成量；一次请求；响应检查 | 参数变更重授权；HTTP 错误或空 text 保持展开；生成内容不等于事实证明 |

## 交互与状态

- 纵向步骤，当前步骤展开；成功收起，用户点击继续才进入下一步。
- 授权显示真实点击对应的用户气泡；命令及模拟结果同步到 IDE 终端。
- 失败显示原因与处理建议；修正参数后重新授权，不自动重试。
- 暂停、取消、手动操作不产生通过结果；手动粘贴只标为用户提供、未经验证。
- 刷新可恢复当前步骤；中断中的演示转为暂停，不伪造后台完成。
- 上游参数变化会使后续完成状态失效，旧结果保留在已失效记录中。
- 代码可复制、置入对应 IDE 文件和撤销；内容已变化时撤销不覆盖。
- 第七步 IDE 运行沿用本次提示词和生成量快照，不误用默认目标。
- 全部完成后可导出 JSON 演示记录或保存在本机预览笔记。

## 验证

- 浏览器完整正常流程：7 步成功、25 子任务、完成自动收起、终端同步。
- Docker 异常阻断；暂停 / 刷新恢复；手动回显不自动通过与基本凭据脱敏。
- 下载上传、镜像安全登录、高权限容器授权门槛。
- 自定义含单引号提示词与生成量 128，置入 IDE 后本地运行比对通过。
- 修改第一步主机后，后六步全部回到未执行，旧记录可查；刷新保留参数。
- 390px 视口无页面横向溢出；IDE 悬浮讲解保留。
