## 社区贡献与开发榜

- [ ] **T-DEV-01：建立“经验反哺—积分—开发榜”闭环**
  - **用户场景**：开发者使用外部开源项目或资料完成开发后，把已经验证的经验整理为社区帖子；平台审核贡献并发放积分，贡献者进入独立的开发榜页面。
  - **关键链路**：完成开发 → 带入代码、日志、环境与指标 → AI 整理经验草稿 → 用户确认内容、来源和公开范围 → 社区发布与验证 → 发放积分 → 更新开发榜。
  - **积分依据**：信息完整度、复现证据、他人验证次数、问题解决数、被课程或官方内容引用、持续维护情况。浏览量和发帖量只作弱参考，避免鼓励灌水。
  - **开发榜结构**：本周贡献、长期贡献、领域榜（算子开发／模型训练／模型推理／推荐开发）；榜单项应显示代表贡献和得分原因，而不只显示总分。
  - **用户反馈**：发布前展示预计可获得的积分区间；审核或复现后说明积分变动原因；个人主页保留贡献记录、验证状态和影响人数。
  - **治理要求**：标注开源项目与原始资料来源；检查许可证、隐私和敏感日志；重复内容合并；被证伪或过期的经验进入复核，不直接永久保留高分。
  - **低保真进展（2026-10-10）**：已完成首页第三楼层与独立开发贡献榜原型。首页支持按算子开发、模型训练、模型推理、推荐开发筛选；独立页支持周榜、长期榜、领域榜，并显示贡献闭环和逐项得分原因。
  - **后续产物**：积分规则表、贡献详情页、开发榜页面、个人贡献卡片、课程实践结束后的回填入口及数据字段。
