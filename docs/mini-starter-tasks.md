## 第一个任务：让偏暗照片亮起来

**目标：**完成一个真正的逐元素加法算子，并看见它如何被 Host 程序调用。完整环境应预置 Ascend C 工程、CANN、兼容的昇腾设备和一张用户可替换的示例图片。

1. **选图与观察输入。**默认给一张偏暗示例图；也可上传自己的照片。先展示一小组归一化像素值，例如 `0.20、0.35、0.50`。图像预处理把像素转换为算子支持的张量类型。
2. **完成一行算子代码。**预置 Device 侧 `add_custom` 核函数的数据搬入、队列和数据搬出部分；用户补上 `AscendC::Add` 对输入张量与同形状亮度张量逐元素相加的调用。亮度张量由 Host 侧填入固定增量，例如 `0.15`。
3. **运行与查看调用。**Host 程序准备两个输入张量和输出张量，启动核函数并读取输出。界面展示调用链“Host 准备输入 → `add_custom` 执行 → Host 读取输出”，并将用户代码与预期加法结果比对。
4. **展示照片。**把输出转换回图像时，将超出显示范围的值裁剪到 `[0,1]`，再换算为 `0–255`。明确标注裁剪是显示后处理，Add 算子本身只做加法。
5. **完成反馈与转场。**展示原图/结果图、输入输出样例、校验结果和运行环境。只有真实 NPU 运行并校验通过时才写“昇腾 NPU 运行通过”；浏览器低保真仅写“交互演示”。完成后首页同一楼层切换为原有课程介绍卡片。

**准确性边界：**官方 Add 样例以两个输入 `x、y` 和输出 `z` 实现逐元素 `z=x+y`，涉及 `DataCopy` 搬入/搬出和 `Add` 计算；CPU 孪生调试只验证功能与精度，不等同 NPU 上板运行。图片提亮是对该算子输入的一种教学应用，图片预处理与范围裁剪须在界面中另行标明。

参考：[昇腾 Ascend C Add 算子实践](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/82RC1alpha001/opdevg/Ascendcopdevg/atlas_ascendc_10_0005.html)、[CPU 域调试说明](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/83RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_00031.html)。
