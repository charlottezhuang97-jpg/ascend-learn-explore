# 知识地图版本

- V1：原开发场景知识地图。独立入口 `knowledge-map-v1.html`，直接脚本、样式依赖冻结于 `versions/knowledge-map-v1/source/`，SHA-256 清单见该目录 manifest.json。快照包含保存时尚未提交的页面改动。
- V2：认证路径版。入口 `knowledge-map.html` 或 `knowledge-map-v2.html`。以生成式AI下的推理开发者认证（工作级）为默认状态。

页面顶部“切回旧版 V1”会记住默认版本；旧版右下角“切换新版 V2”可再次切换。两个版本分别保存课程选择，不覆盖彼此的课程数据。

V2 可点击课程目录、案例、考试要求与证书说明，可编辑课程并接入学习计划。目录与案例为根据参考课程描述整理的示意，考试领域与占比来自用户提供的参考图。
